# Install Fabric

**[Follow the Windows or Mac setup guide →](/docs/minecraft/installation)**

Step **(4)** covers downloading the Fabric installer and choosing the correct Minecraft version. Step **(7)** shows you how to select the new Fabric profile in the launcher.

When upgrading from 1.21.8, install Fabric for the new game version too. Your old Fabric profile continues to launch the old version.

Fabric API is already included in our modpack. You do not need to download it separately.
