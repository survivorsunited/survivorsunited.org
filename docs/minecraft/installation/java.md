# Install Java

**[Follow the Windows or Mac setup guide →](/docs/minecraft/installation)**

Step **(3)** covers installing Java 21 with a normal download and installer. On Mac, it explains which download to choose for an Apple silicon or Intel computer.

Java is needed to open the Fabric installer. The official Minecraft Launcher manages Java for the game itself. If Java 21 is already installed on your computer, you can skip this step.
