# Install Minecraft

**[Follow the Windows or Mac setup guide →](/docs/minecraft/installation)**

Step **(2)** covers installing the official Minecraft Launcher and signing in. Continue through the same guide to install Fabric, add the mods, and join the server.

If you already have the launcher, keep it. The guide explains how to upgrade from an older game version without reinstalling Minecraft.
