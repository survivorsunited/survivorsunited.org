# Install or Update Mods

**[Follow the Windows or Mac setup guide →](/docs/minecraft/installation)**

Step **(1)** covers downloading and extracting the modpack. Steps **(5) and (6)** show you exactly where to put its mod files on your computer.

<details>
<summary>Release reference</summary>

[View the modpack release](${DOWNLOAD_LINK_MODPACK}). For installation, use the wizard's direct download so you get the pack matching the server.

</details>

**Updating an existing installation?** Close Minecraft and its launcher, move your old **mods** folder out of the game folder as a backup, then create a fresh **mods** folder for the new pack. Copy the new `.jar` files into it. Overwriting files can leave old versions behind and cause Minecraft to fail to start.

Keep your worlds, settings, and maps. The setup guide explains what to preserve and how to find a custom game folder.
